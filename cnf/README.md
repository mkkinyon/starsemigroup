# CNF files for kissat — SAT validity checks of the chain conditions in P(P_m)

Each file encodes "there is an instance of the hypotheses of the condition in P(P_m) in which one half of the
conclusion a |><| b fails" (file _1: theta_a(b) != a... the two halves are the two files).  So:

    the condition is VALID in P(P_m)  <=>  BOTH files are UNSATISFIABLE.

A SATISFIABLE answer would be a counterexample: please send me the solver output (the "v ..." lines), I can
decode the model into partitions.

How to run (one core, no time limit; add --time=36000 for a 10-hour cap):

    kissat W3_m6_1.cnf > W3_m6_1.out ; kissat W3_m6_2.cnf > W3_m6_2.out
    grep "^s " *.out        # prints s UNSATISFIABLE / s SATISFIABLE / nothing if interrupted
